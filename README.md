# README.md

## 1. サービス概要
- サービス名：人生後半戦スイッチ（仮）
50代男性が感じる漠然とした不安や、若い頃のようなガッツやチャレンジ精神が薄れてきた時に、背中を押してくれるアプリ。今の状況・悩み・気持ちを選ぶだけで、AIが同じ境遇から逆転した偉人のエピソードを提示してくれる。「あの人もそうだったのか」という発見が、もう一歩踏み出す勇気につながる。

---

## 2. このアイデアはどこから生まれたか
### 2-1. きっかけとなった体験・感情
Webディレクターとして働く中で、プログラミング知識がないことで、クライアントの要望よりもプログラマーの都合に偏った提案をしてしまっていた。「本当にクライアントのためになる提案ができていないのでは」という違和感が長年あった。

50代になり、今こそその課題を解決しようとRUNTEQに入校した。新しい技術を身につけ、今後のキャリアとプライベートに活かすための挑戦である。この体験そのものが「人生後半戦の逆転」であり、同じように挑戦したい50代男性を元気づけたいという気持ちからこのアプリが生まれた。

### 2-2. なぜそれが「気になった」のか
「クライアントファーストであるべき」という自分の価値観と、知識不足による現実のギャップに違和感をもっていた。知識がないことで選択肢が狭まることへの悔しさが長年あった。

また、50代でRUNTEQに入校した自分自身が、このアプリのユーザーそのものであるという実感がある。同じように「このままでいいのか」と感じている50代男性に、逆転した偉人のエピソードを通じて背中を押したいという強い動機がある。
---

## 3. 課題の整理
### 3-1. 表に見えている困りごと
50代男性が仕事の場面で感じる「このままでいいのか」という感覚。昇進が止まった、役割が変わった、若手に抜かれた、転職すべきか悩んでいるなど、キャリアの行き詰まりを誰にも相談できずにいる。

### 3-2. 本当に解決したい課題は何か
- なぜ？ → 50代男性は仕事・キャリアで「このままでいいのか」という漠然とした不安を感じる
- なぜ？ → 「自分で解決すべき」という信念・恥ずかしさ・相談しても共感してもらえない経験から、誰にも話せない
- なぜ？ → 一人で抱え込むことで不安が消えず、新しい挑戦に踏み出せなくなる
- 本当に解決したい課題： 50代男性が仕事・キャリアへの不安を一人で抱え込み、若い頃のようにチャレンジできなくなっている
- なぜ偉人エピソードなのか：アドバイスや優しい言葉は、相談しづらい50代男性には響きにくい。しかし「カーネルサンダースも65歳で失敗していた」という事実は、言葉ではなく証拠として心に刺さる。共感ではなく実例が、行動変化を起こす。

## 4. 想定ユーザーについて
### 4-1. 想定しているユーザー
年齢設定：
  - 年齢：50代前後の男性
  - 理由：キャリアの転換期を迎え、仕事への不安を抱えやすい世代。管理職・役職定年・転職など、仕事上の悩みが集中する年代。

生活・状況設定：
  - 生活・状況：仕事でうまくいかなかった日、キャリアへの不安を感じた瞬間、新しい挑戦を躊躇している時
  - 理由： 仕事で失敗した帰り道や、ふと将来が不安になった夜など、一人になる瞬間にさっと開けるアプリとして設計する

環境設定：
- 環境：スマートフォンを持ち、日常的にアプリを使える50代男性
- 理由：移動中や就寝前など、一人になる時間に手軽に使えることで、相談しづらい悩みを気軽に吐き出せる

### 4-2. 自分とユーザーの距離
- 自分自身： 50代でRUNTEQに入校し、新しい挑戦をしている当事者として、ユーザーの気持ちをリアルに理解できる。漠然とした不安やチャレンジへの躊躇を自分自身が経験しているため、ユーザーの感情に寄り添った設計ができる。

### 4-3. 実際に使われる可能性について
- 最初に使ってくれそうな人： 同世代の知人・友人（50代前後の男性）
- どんな場面で思い出すか：「最近なんか元気ないな」「あいつ最近落ち込んでるな」という時に、知人から「こんなアプリあるよ」と紹介される流れが自然
- 今の代替手段：名言アプリや自己啓発本
- 置き換える理由：相談できる場所がない50代男性にとって、気軽に使える唯一の「背中を押してくれる場所」になりうる

### 4-4. ユーザーがサービスを導入して利用するまでのイメージ
- きっかけ： 仕事で失敗した日、ふと将来が不安になった夜、知人からの口コミ
- 最初の一歩： メールアドレスとパスワードで簡単登録。すぐに悩みを選択して偉人を探せる
- 使い続ける理由： 落ち込んだ時に開く→偉人に救われる→また落ち込んだ時に開く、というサイクルが生まれる。「お守りアプリ」としての役割を果たす
- AIだからこその体験：固定コンテンツではなく、その日の気持ち・状況に合わせて毎回違う偉人が出てくる。自分の状況が変われば出会う偉人も変わるため、何度使っても新鮮

## 5. 既存サービス・競合調査
### 5-1. 似たサービスの調査
- サービス名①： Motivation - 今日の名言
- URL：https://apps.apple.com/jp/app/motivation/id876080126
- できること：毎日の名言表示・お気に入り保存・ウィジェット機能。評価4.7・3465件の人気アプリ

- サービス②：OpenWork 偉人タイプ診断**
- URL：https://openworkcp.com/shindan/
- できること：34問の質問に答えると、自分のタイプに近い幕末明治の偉人や仕事上の強み・弱みがわかる

### 5-2. それでも作りたい理由
- Motivationへの不満：
名言が一方的に届くだけで、自分の今の状況や悩みに合わせた偉人に出会える機能がない。受け身のコンテンツ消費になってしまう。

- OpenWork偉人診断への不満： 転職サイトの集客ツールとして作られており、偉人との「共感・励まし」が目的ではなく就職・転職活動への誘導が目的。50代男性の人生全般の悩みには対応していない。また結果が固定パターンのため、何度使っても同じ結果になる。

### 5-3. 差別化を一文で決める
- 差別化ポイント：「漠然とした不安を感じ、チャレンジする気持ちが薄れてきた50代男性が、今の自分の状況を入力した瞬間に、同じ境遇から逆転した偉人に出会い、前に進む勇気をもらえる唯一のアプリ」

## 7. このアプリで実現すること
### MVPで作る機能
- 年齢・悩み・気持ちの選択画面（選択項目のバリエーションをできるだけ充実させ、AI出力のパターン数が増えるように設計する）
- AIによる逆転偉人エピソードの生成・表示
- ユーザー登録・ログイン機能
※AIを活用することで、ユーザーの状況・気持ちの組み合わせに応じて毎回異なる偉人エピソードを生成できる。固定コンテンツでは実現できない、パーソナライズされた体験が最大の特徴。

### 本リリースで作る機能
- お気に入り保存機能
- 毎朝の名言・偉人エピソード通知機能
- 保存した偉人エピソードの一覧・見返し機能
- 趣味・好きなことの入力項目追加（より精度の高い偉人マッチング）
- 関連書籍の紹介機能（偉人エピソードと合わせてAIが関連書籍名とリンクを提示）

## 8. このアプリの懸念点
- 懸念点：  AIが偉人のエピソードを生成する際に、事実と異なる情報や誇張された内容を出力してしまう可能性がある
- なぜそう思うか： AIは学習データをもとに文章を生成するため、細かい年齢や出来事の詳細が実際の史実と異なる場合がある。ユーザーがその情報を信じてしまうと、誤った知識が広まるリスクがある
- 対策： 結果画面に「エピソードはAIによる生成のため、詳細は各自でご確認ください」という免責表示を入れる

## 10. 技術スタック
- 言語： Ruby
- フレームワーク： Ruby on Rails
- DB： MySQL
- デプロイ先： Render または Heroku
- 使用予定ライブラリ： Devise（ユーザー認証）、faraday（API通信）

### 10-2. 技術選定の理由

- RUNTEQで学んでいるRuby on Railsをそのまま活用することで、キャッチアップコストを最小限に抑え、1ヶ月以内の完成を現実的にした
- 今回チャレンジしたい点：Anthropic APIとRailsの連携実装

### 10-3. キャッチアップ不足の懸念

開発スケジュールは以下を想定しています

- 1週目：環境構築・ログイン機能
- 2週目：選択画面・API連携実装
- 3週目：結果表示・UI調整
- 4週目：テスト・デプロイ・仕上げ

ただし、このスケジュール通りに進まない可能性がある。特にAPI連携の実装や想定外のバグ対応で時間を取られるリスクがある。その場合は、UI調整など優先度の低い作業を後回しにし、コア機能（選択画面・AI結果表示・ログイン）の完成を最優先とする。

まずAPI連携の技術検証を優先し、動作確認が取れた上でUI実装に進む順序で開発を進める。
